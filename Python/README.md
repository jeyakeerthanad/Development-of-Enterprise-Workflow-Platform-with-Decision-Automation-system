## Project Overview
This project focuses on practising core Python programming through 10 problems on numbers, strings, and lists. Each problem includes a natural-language prompt, a solution, sample output, and a short explanation of the logic used.

## Tools Used
- Python 3
- Google Colab

## Concepts Covered
- Loops (`for`)
- Conditional Statements (`if`, `elif`, `else`)
- String Manipulation (slicing, `lower()`, `replace()`)
- List Operations (`append`, indexing, traversal)
- Built-in Functions (`sorted()`, `len()`, `abs()`)
- Tracking values with variables (largest / smallest / second largest)
- Handling edge cases (negative numbers, empty lists, unequal list lengths)

## Problems Solved
1. Factorial of a number
2. Palindrome string check
3. Remove duplicates from a list (order preserved)
4. Second largest number in a list (without `sort()` / `sorted()`)
5. Anagram check
6. Power of a number (without `**` or `pow()`)
7. Count occurrences of a character
8. Merge two lists alternately
9. Common characters between two strings
10. Difference between largest and smallest numbers (without `max()` / `min()`)

## Project Structure
- `Python_task.ipynb`: Contains the problem statements, prompts, Python solutions, sample outputs, and the logic behind each solution.

## How to Run
1. Download or clone this repository.
2. Open `Python_task.ipynb` in Google Colab or Jupyter Notebook.
3. Run the cells in order to view the outputs.
4. To test with different inputs, change the sample values at the top of each code cell (for example, `n = 5` or `text = "Madam"`).

## Objective
To build a strong foundation in Python programming and problem-solving by implementing common logic-based problems using loops, conditions, strings, and lists.
